# NCS 분류 데이터

`categories.csv`는 NCS(국가직무능력표준) 분류의 대분류·중분류·소분류·세분류 1,201건이다.

| 항목 | 내용 |
|---|---|
| 출처 | 공공데이터포털 「학교법인한국기술교육대학교_원격훈련심사센터_NCS(국가직무능력표준)분류」 https://www.data.go.kr/data/15153998/fileData.do |
| 기준일 | 2025-11-25 (포털 등록일), 연 1회 갱신 |
| 이용 조건 | 이용허락범위 제한 없음, 무료 |
| 받은 날 | 2026-11-16 |

## 원본에서 바꾼 것

- 원본은 코드와 명칭 두 칸이고, 능력단위와 능력단위요소까지 42,901건이 들어 있다. 이 중 숫자만으로 된 8자리 이하 코드(분류 4단계)만 남겼다.
- 원본 코드는 앞자리 0이 빠져 있다(예: `2010101`). 단계별 2자리씩이 되도록 0을 채웠다(예: `02010101`).
- `level`은 1 대분류(24건), 2 중분류(79건), 3 소분류(231건), 4 세분류(867건). 상위 코드는 코드의 끝 2자리를 뗀 것이다.

분류의 최신 정보는 https://www.ncs.go.kr 에서 확인한다.
